Diese Website ist die inoffizielle Vereinswebseite des TSV Fortuna Götzingen.
Sie dient zur Darstellung von Vereinsinformationen, aktuellen Ergebnissen, Mannschaftskader, Spielplan, Sponsoren sowie allgemeinen Vereinsinformationen.

JavaScript-API
Zur Darstellung von Mannschaftsdaten, Spielplänen und Tabellen nutzt die Website offizielle Widgets von fussball.de. Diese Widgets werden direkt über ein externes JavaScript eingebunden und ermöglichen es, aktuelle und automatisch gepflegte Inhalte des Deutschen Fußball-Bundes anzuzeigen, ohne diese selbst verwalten zu müssen. 
Jedes Widget ist über eine eindeutige Kennung (ID) konfiguriert, die den jeweiligen Verein, das Team oder den Wettbewerb eindeutig identifiziert. 
Diese IDs werden als sogenannte data-id Attribute im HTML hinterlegt und stellen sicher, dass stets die korrekten Vereinsdaten geladen werden. 
Änderungen an Ergebnissen, Spielansetzungen oder Tabellenständen erfolgen somit automatisch über fussball.de und sind immer aktuell, ohne dass manueller Pflegeaufwand auf der Website entsteht.
